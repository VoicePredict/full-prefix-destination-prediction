# Reference bundle

This directory contains the immutable material needed to audit the reported
results without downloading GeoLife or retraining the models.

| Directory | Contents |
|---|---|
| `manifests/` | Dataset, cohort, split, run-provenance, and environment records |
| `predictions/` | Coordinate-free case-level records for paired analyses |
| `results/` | Validated statistics copied from the reference runs |

All files are covered by the repository-level `SHA256SUMS` manifest.

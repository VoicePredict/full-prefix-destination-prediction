# Reporting outputs

`expected_claims.json` is the machine-readable set of rounded numerical claims
checked against the underlying frozen files by `scripts/verify_artifact.py`.

`paper_tables/` contains compact CSV views of the tables and textual result
blocks used in the manuscript. With the exception of the cohort-characteristic
extract, these files are regenerated by `scripts/export_paper_tables.py`.
The cohort extract combines discovery and evaluation summaries whose full
recalculation requires the training-only catalogues; the complete pipeline
regenerates those catalogues locally from GeoLife.

`figures/` contains SVG versions generated directly from frozen outputs. The
manuscript build may convert them to PDF, but the data-bearing SVGs are kept
here because they are text-readable and platform independent.
